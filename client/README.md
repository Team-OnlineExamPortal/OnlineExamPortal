# Client (React Frontend)

This folder will hold the React application.

## To initialize

From the repo root:

```bash
cd client
npx create-vite@latest . -- --template react
# or: npx create-react-app .
npm install
```

## Planned structure (per SAD)

- Login / registration screens
- Student dashboard (available exams, results)
- Exam screen (question, options, timer, navigation, review state)
- Admin dashboard (question bank, exam scheduling, reports)
